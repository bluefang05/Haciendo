# Privacidad y tratamiento de datos

- No se requiere cuenta.
- No se suben proyectos automáticamente.
- Las fotos y notas se guardan localmente.
- Compartir ocurre solo por acción del usuario mediante Android.
- El PIN es una barrera de interfaz, no cifrado del almacenamiento.
- El banner publicitario puede comunicarse con Google AdMob.
- Debe incorporarse UMP/consentimiento cuando aplique por región y política.
- Los documentos y archivos exportados no incluyen anuncios.
- Los avances marcados privados se excluyen por defecto de exportaciones compartibles.
